# 慢慢过 · 学位英语

[打开学习应用](https://akamoxi.github.io/manmanguo-english/)

面向英语基础薄弱成人学习者的移动 H5 应用。手机、平板和电脑均可使用；不需要注册，页面没有外部脚本、字体或图片依赖。

## 功能

- 80 个基础词汇及常用表达，配音标、例句、中文和设备语音朗读。
- 四份自考英语资料共 2557 条：核心单词 1844 条、新增单词 183 条、否定前后缀 26 条、固定搭配 504 条。保留资料内的重复词及原文件。
- 自考资料支持分类搜索、分页、词卡、每轮 10 题的词义练习，以及错题订正、间隔复习与备份恢复。首页点击“打开资料库”进入。
- 8 课句子与基础语法，逐块拆解主语、谓语和宾语。
- 124 道原创基础题，含 4 篇短文、8 题入门测评及每日练习。
- 错题自动归集、重练订正、词卡间隔复习。
- 20 题 / 20 分钟基础限时练习，支持暂存和恢复。
- 学习计划、考试日期、JSON 备份导入导出与离线使用。

## 使用与数据

用浏览器打开应用即可学习。手机浏览器支持时，可从菜单添加到主屏幕。首次成功加载后，支持的浏览器可以离线练习。

学习进度只保存在当前设备、当前浏览器的本地存储中，不上传到 GitHub，也没有账号云同步。更换设备、网址或清理浏览器前，到“我的计划”导出备份，在新页面导入后继续学习。之前 ChatGPT 网站地址与本网站的记录不会自动互通。

语音朗读依赖设备提供的英语语音服务；没有可用语音时，词卡与文字练习仍然可以使用。

## 内容范围

本项目是英语基础补习工具，不是上海大学官方应用，也不是学校真题库。各达标路径目前共用基础词句练习，没有分别提供完整的听力、写作和全真试卷。基础练习得分不折算正式考试成绩或通过概率。

## 本地运行和维护

本项目无需构建或安装依赖。可直接打开 `index.html`；如需测试离线缓存，在本目录运行：

```sh
python -m http.server 8768
```

访问 `http://localhost:8768/`。网站通过 GitHub Pages 从 `main` 分支根目录发布。更新 `app.js`、`data.js`、`style.css` 等资源后推送即可触发发布。所有资源使用相对路径，支持 GitHub Pages 的仓库子路径。

本项目的更新发布到 [akamoxi/manmanguo-english](https://github.com/akamoxi/manmanguo-english)，正式访问地址为本页顶部的 GitHub Pages 链接。后续修改继续使用这个仓库和地址。

资料集成回归检查可运行 `node qa_materials.mjs`，覆盖资料数量与答案映射、页面生成、分类词卡、搜索分页、错题订正、复习、备份恢复及旧记录兼容性。
